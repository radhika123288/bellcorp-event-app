# Bellcorp Event App

A full-stack Event Management application built with **React** (frontend) and **Node.js/Express + MongoDB** (backend).  
Users can view events, register, and log in. The app is deployed with **Vercel** (frontend) and **Render** (backend).  

---

## 📁 Project Structure
---

## ⚙️ Features

- User registration and login  
- View event list  
- Fetch and display data from MongoDB  
- Full-stack deployment with live backend and frontend  
- Environment variables for secure API access  

---

## 🛠️ Tech Stack

- Frontend: React, Axios, React Router  
- Backend: Node.js, Express.js, Mongoose  
- Database: MongoDB Atlas  
- Hosting: Vercel (frontend), Render (backend)  

---

## 🔹 Prerequisites

- Node.js (v16 or above recommended)  
- npm (Node Package Manager)  
- MongoDB Atlas account (for backend database)  
- GitHub account (for deployment)
